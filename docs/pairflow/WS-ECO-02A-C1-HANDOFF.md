## Changes Made

### #1 Fix TTS Backend Semantics

**Before:** `ttsBackend: "python"`
**After:** `ttsBackend: "edge"`

**Source of truth:** `gen_tts_solarSystem.py` line 5: `import edge_tts`

The actual TTS engine is `edge_tts` (Microsoft Edge TTS). Python is only the process launcher. The provenance now records the actual engine identity.

### #2 Record Actual Voice

**Before:** `voice: null`
**After:** `voice: "vi-VN-NamMinhNeural"`

**Source of truth:** `gen_tts_solarSystem.py` line 8: `VOICE = "vi-VN-NamMinhNeural"`

The voice is now derived from the existing configuration used by the TTS implementation, not duplicated in a second source of truth.

### #3 Record Real Duration

**Before:** `duration: null`
**After:** `duration: <total from durations.json>`

**Source of truth:** `public/solarSystem/durations.json` (generated by `gen_tts_solarSystem.py` using `mutagen.mp3.MP3` to measure actual MP3 artifact durations)

Duration is now read from the actual generated artifact durations (not planned scene timing). The `readArtifactDuration()` function sums all scene durations from `durations.json`.

### #4 Reconcile Production Source of Truth

**Before:** `produce.mjs` loaded `scripts/manifest.json` as canonical
**After:** `produce.mjs` loads `contract.json` as canonical, merges additional metadata from `scripts/manifest.json`

**Resolution:**
- `contract.json` = canonical production definitions (id, composition, output, format)
- `scripts/manifest.json` = internal build metadata (template, aliases, keywords, dataFile, tts, resolution, preview)

The `buildProductions()` function in `produce.mjs` now reads from `contract.json` first, then merges in additional fields from `scripts/manifest.json`. This ensures `contract.json` is the single canonical source for production identities.

### #5 Provenance Failure Semantics

**Defined behavior:**
```
artifact-producing capability succeeds
+
provenance successfully persisted
=
SUCCESS
```

If provenance persistence fails:
```
FAILED
```

Provenance is required evidence for artifact-producing capabilities. The capability does not silently report complete success while required provenance is missing.

**Implementation:** In `produce.mjs`, provenance failure now returns `false` (capability FAILED) instead of just warning.

### #6 Real Integration Evidence

Added integration tests in `src/__tests__/provenance.vitest.ts` that verify:
- SolarSystem TTS backend is `edge_tts` (not python) — reads actual `gen_tts_solarSystem.py`
- SolarSystem voice is `vi-VN-NamMinhNeural` — reads actual `gen_tts_solarSystem.py`
- SolarSystem `durations.json` exists and contains valid durations
- SolarSystem total duration matches sum of scene durations
- `contract.json` exists and is valid JSON
- SolarSystem production exists in `contract.json`
